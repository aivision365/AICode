# AICode
AI parses and generates code with a small assistant that works with any code editor without the need for other tools

AI解析和生成代码小助手,适用于任何代码编辑器,无需借助其他工具



# Note: 

first GenAICode. Cs interface DeepSeekApiKey fill out their own key, the key to obtain the address is: https://platform.deepseek.com/api_keys

首先GenAICode.cs界面的DeepSeekApiKey处填写自己的key,key获取地址为:https://platform.deepseek.com/api_keys

F6 code parsing needs to request api return may be slow please wait

F6代码解析需要请求api返回可能会慢请耐心等待
# Usage:

Write code:
Shortcut F2, make a request, then place the cursor where you want to generate the code Press F4, and the code will be written at the cursor position.
Parse the code:
Shortcut key F2, make a request, copy the code to be parsed to the clipboard, not too many lines, within 10 lines, click the shortcut key F6, wait a few seconds will pop up the parsing dialog box

写代码:
快捷键F2,提出要求,然后把光标放置在想生成代码的地方按F4,会在光标位置写代码.
解析代码:
快捷键F2,提出要求,复制要解析的代码到剪切板,不要太多行,10行以内,点击快捷键F6,稍等几秒钟会弹出解析对话框
